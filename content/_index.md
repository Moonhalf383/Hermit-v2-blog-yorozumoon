## Navigation

本站支持 vim 的交互逻辑，你可以只使用键盘来阅读本站的文章。如果不了解 vim ，可移步[此教程](https://csdiy.wiki/%E5%BF%85%E5%AD%A6%E5%B7%A5%E5%85%B7/Vim/)。一些简单的操作方法如下：

- `Ctrl-h` / `Ctrl-l` 在文件树、正文和大纲之间移动焦点。
- `j` / `k` 移动，`h` / `l` 收起、展开或打开条目。
- `H` / `L` 收放左右侧栏。
- `?` 查看完整帮助。
